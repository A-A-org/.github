# School ERP SaaS

A scalable SaaS-based School Management System designed to help educational institutions manage students, employees, attendance, fees, exams, and daily operations in one centralized platform.

## 📌 Project Overview

School ERP SaaS is a full-stack web application that provides schools with a complete digital management solution.

The platform allows different users to manage school activities based on their roles and permissions.

## 👥 User Roles

### 1. Platform Owner
- Manage schools
- Manage subscriptions
- View analytics
- Manage users and permissions

### 2. School Admin
- Manage students
- Manage employees
- Manage classes
- Manage attendance
- Manage fees
- Manage exams and results

### 3. Employee
- Take attendance
- Enter marks
- Manage assignments
- Access assigned student information

## 🚀 Planned Features

- Authentication system
- Multi-school support
- Student Management
- Employee Management
- Attendance System
- Fee Management
- Exam & Result Management
- Reports and Analytics
